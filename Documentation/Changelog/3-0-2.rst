Breaking changes
----------------

Classic installations from a Git checkout or a GitHub source archive now need
``composer build-extension`` before activation. The TER package includes the
SimplePie bundle.

Use ``composer build-extension`` in place of ``composer create-libs``.
Run tests, linters and coverage through ``Build/Scripts/runTests.sh``.
